# XReal3D

Mobile-first C++ 3D game project.

## Technology

- C++
- raylib
- Android NDK
- CMake
- OpenGL ES
- GitHub Actions

## Assets

Put 3D models in:

`assets/models/`

Put textures in:

`assets/textures/`

Put shaders in:

`assets/shaders/`

Put animations in:

`assets/animations/`

Put sounds/music in:

`assets/audio/`

Put maps in:

`assets/maps/`

Recommended model format:

`.glb`

## Android

Target ABI:

`arm64-v8a`

Build system:

GitHub Actions + Android NDK + CMake.
